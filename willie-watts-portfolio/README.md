# Willie Watts Portfolio Website

## Overview

This project is a professional portfolio website developed using React and Vite. The site showcases my background in supply chain management, business analytics, systems analysis, database design, and web development. It was designed to serve as a centralized platform for presenting professional experience, technical skills, academic projects, certifications, and contact information.

The portfolio demonstrates modern frontend development concepts including component-based architecture, client-side routing, responsive design, dynamic content rendering, form validation, and reusable UI components.

## Installation

### Clone Repository

```bash
git clone https://github.com/wwatts-bu/willie-watts-portfolio.git
```

### Navigate to Project Directory

```bash
cd willie-watts-portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Create Production Build

```bash
npm run build
```
